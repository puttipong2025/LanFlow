# Edit draft Rubber Export membership and mark verified exports as sold out

LanFlow จะให้ปุ่ม `แก้` เฉพาะ REX ฉบับร่างเพื่อแทนที่สมาชิกทั้งชุดใน transaction เดียว โดย modal เลือกสมาชิกเดิมไว้ก่อนและรวมบิลว่างที่พร้อมเลือก การบันทึกต้องเหลืออย่างน้อยหนึ่งบิล ตรวจ eligibility ของทั้งชุด ปลดการจองของบิลที่เอาออก จองบิลที่เพิ่ม คำนวณน้ำหนัก ต้นทุน และอายุใหม่ แล้วล้างน้ำหนักปัจจุบัน ค่าทำงาน และค่าดำเนินการเดิมทั้งหมด; สมาชิกของรายการที่ตรวจสอบแล้วคง immutable.

REX ที่ตรวจสอบแล้วและยังไม่มีบิลปลายทางอ้างถึงสามารถมีเครื่องหมายย้อนกลับได้ `ขายยางออก` ภายใต้สถานะหลักเดิม โดยเก็บเฉพาะผู้กดและเวลาของสถานะปัจจุบัน ไม่สร้างรายรับ บิลขาย ราคา ผู้ซื้อ หรือตารางประวัติ. การขายและยกเลิกต้องยืนยันและทำผ่าน Server transaction; สถานะขายกันการรับยางและการลบ แต่ยังเปิด Detail และ PDF ได้ อยู่ทั้งในตัวกรอง `ตรวจสอบแล้ว` และ `ขายออกแล้ว` พร้อมป้าย `ขายออกแล้ว`, และต้องกด `ยกเลิกขาย` ก่อนลบ. ตัวกรอง `ขายออกแล้ว` แทน `ใช้งาน` ซึ่งซ้ำกับ `ทั้งหมด`, และหน้าเริ่มที่ `ทั้งหมด`. การใช้สถานะย่อยแยกจาก lifecycle หลักหลีกเลี่ยงการทำให้ verified snapshot, report expense และ PDF เปลี่ยนความหมาย ขณะที่ row lock ทำให้การขายกับการรับพร้อมกันสำเร็จได้เพียงฝั่งเดียว.
