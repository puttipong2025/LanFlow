# เก็บประวัติโอนเงินเดือนโดยนับเฉพาะส่วนสาขาจ่ายในยอดสะสม

ผู้ใช้ยืนยันเมื่อ 2026-10-31 ให้เงินเดือนใช้โอนเงินลูกค้าเป็นต้นแบบ: ส่วนโอนและสลิปยังตรวจย้อนหลังได้ แต่เฉพาะส่วนสาขาจ่ายเท่านั้นที่กระทบรับ–จ่ายสุทธิสะสม เพื่อไม่หักยอดโอนซ้ำกับรายจ่ายสาขา เก็บการคำนวณรายการเก่าไว้จนกว่าจะยืนยันช่องทางจ่ายได้ แทนการตีความข้อมูลเก่าใหม่ทั้งชุดซึ่งอาจเปลี่ยนยอดย้อนหลังโดยไม่มีหลักฐาน

ข้อสรุปเพิ่มเติม: ค่าใช้จ่ายดำเนินงานนับยอดเงินเดือนสุทธิเต็มจำนวนที่สาขารับค่าใช้จ่าย แม้มีส่วนโอน เช่น ยอดสุทธิ 15,000 โอน 10,000 สาขาจ่าย 5,000 ทำให้รับ–จ่ายสุทธิสะสมลด 5,000 แต่ค่าใช้จ่ายดำเนินงานเพิ่ม 15,000 และใช้ 15,000 คำนวณเปอร์เซ็นต์ สูตรแยกส่วนนี้ใช้กับเงินเบิกด้วยโดยรักษาการหักเงินเบิกในสลิปตามเดิม
