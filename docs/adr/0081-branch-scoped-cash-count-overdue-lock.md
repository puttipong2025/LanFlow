# ล็อกเกินกำหนดนับเงินระดับสาขาด้วยช่วงปลดล็อกชั่วคราว

สถานะ: ยืนยันและตรวจรับใน local แล้ว ใช้ migration บน Cloud 2026-10-26 ตามคำสั่งผู้ใช้ ทุกกลุ่มยังปิดล็อกตามค่าเริ่มต้น

ใช้กำหนดนับเงินและสมาชิกกลุ่มเดิมคำนวณการล็อกงานการเงินของสาขา เก็บเพิ่มเฉพาะการตั้งเวลาของกลุ่มกับช่วงปลดล็อกชั่วคราวของสาขา ไม่สร้างสถานะล็อกที่ต้องสลับด้วยงานตั้งเวลา และไม่ใช้คำขออนุมัติเบราว์เซอร์เป็นคำขอปลดล็อก เพราะการอนุมัติเบราว์เซอร์เป็นรายบัญชี/เบราว์เซอร์ แต่เงื่อนไขนับเงินเป็นรายสาขา

หลังเทียบกับโครงสร้างจริง ให้เก็บช่วงอนุญาตบนสมาชิกกลุ่ม `cash_count_alert_members` ซึ่งหนึ่งสาขามีได้หนึ่งแถว แทนการเพิ่มข้อมูลที่ตารางสาขา การออก/ย้าย/ลบกลุ่มจึงใช้การสิ้นอายุสมาชิกเดิมล้างข้อมูลได้ ส่วนการปิดล็อกหรือบันทึกผลนับต้องล้างค่าโดยตรง ไม่เพิ่มตารางสถานะอีกชุด

Super Admin และผู้จัดการระบบปลดล็อกได้ตามสิทธิ์เข้าถึงสาขาเดิม รวมสาขาตัวเองแม้ถูกล็อกอยู่ โดยทุกคนในสาขาใช้ช่วงอนุญาตร่วมกัน ข้อนี้ผู้ใช้ยืนยันให้ต่างจากข้อจำกัดอนุมัติเบราว์เซอร์ที่ผู้จัดการระบบไม่อนุมัติตัวเอง การปลดล็อกเกินกำหนดต้องไม่ข้ามล็อกระหว่างกำลังนับเงินจริง และต้องเปิดทางให้นับเงินแก้เงื่อนไขได้เสมอ

การเปิดทางนับเงินไม่ยกเว้น blocker งานค้างเดิม หากต้องซิงก์หรือแก้รายการก่อนนับ ให้ใช้การปลดล็อกชั่วคราวจัดการงานค้างก่อน ไม่ข้ามการตรวจยอดตั้งต้น เพิ่มการแยกรหัสล็อกในคิว สถานะสาขาที่ไม่หายเมื่อปิดแจ้งเตือน และการทำงานพร้อมกันด้วย transaction เป็นเกณฑ์ส่งมอบ
