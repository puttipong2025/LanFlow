# รายงานรับ–จ่ายนับเงินเดือนเฉพาะส่วนสาขาจ่ายและแก้สายยอดรายงานเดิม

ผู้ใช้ยืนยันเมื่อ 2026-11-01 ให้ยอดรับ–จ่ายรายงานนับเฉพาะส่วนสาขาจ่ายตามกติกายอดสะสม ส่วนโอนยังคงแสดงในหมวดโอนเงินและค่าใช้จ่ายดำเนินงานยังนับยอดเงินเดือนสุทธิเต็มจำนวน การแยกนี้ป้องกันรายงานหักส่วนโอนซ้ำโดยรักษาข้อมูลค่าใช้จ่ายและหลักฐานการจ่ายไว้

เลือกแก้ยอดเปิด–ปิดของรายงานเก่าที่ได้รับผลและยอดยกมาต่อเนื่อง พร้อมหลักฐานก่อน–หลัง โดยคงเลขรายงาน รายการต้นทาง และสลิป แทนสร้างรายการรับ–จ่ายปรับปรุงที่อาจกระทบยอดเงินจริงอีกครั้ง ต้องตรวจผลก่อนใช้กับระบบจริง

ใช้ migration 20261101030000 ใน Local และตรวจผ่านแล้ว กติกาเดียวกันครอบคลุมเงินเบิกที่ใช้ช่องทางจ่ายร่วมกัน ตรวจ Cloud แบบอ่านอย่างเดียวพบรายงานสาขาคำบอน 1 ฉบับ ยอดปิดต้องเพิ่มกลับ 10,000 บาท รายละเอียดและหลักฐานใน ../payroll-report-branch-reconciliation-20261101.md; ยังไม่ได้แก้ Cloud

นำขึ้น Cloud เฉพาะ migration นี้แล้วเมื่อ 2026-11-01 เวลา 22:44 น. ผู้ใช้จัดการรายงานเดิมเองก่อนนำขึ้น จึงไม่เหลือรายงานให้ซ่อมย้อนหลัง ตรวจสูตรตรงกับ Local ที่ทดสอบและข้อมูลต้นทาง/สลิป/ผลนับเงิน/รายงานเดิมไม่เปลี่ยน
