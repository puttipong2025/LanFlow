# ลบรายการโอนค่าทำงานตามรายการส่งออกยางต้นทาง

เมื่อ REX ที่ยืนยันจ่ายภายนอกมี `floor(work_total)` มากกว่าศูนย์และถูกตรวจสอบหลังเปิดใช้กติกานี้ ระบบสร้างรายการโอนค่าทำงานหนึ่งรายการเป็นสถานะรอโอนโดยไม่มีสลิปและไม่เก็บข้อมูลผู้รับเงิน ยอดที่ต้องโอนเป็นยอดเต็มบาทจากการตัดเศษสตางค์ของ `work_total` ทิ้งเสมอ ขณะที่ REX และสลิปยังเก็บทศนิยมสองตำแหน่ง ไม่มีการสร้างหรือแก้ย้อนหลังให้รายการโอนเดิม ในโมดูลโอนเงินให้แสดงเลข REX และชื่อสาขาต้นทางของ REX ชัดเจน โดยสาขาต้นทางไม่ใช่ผู้รับเงิน รายการโอนนี้ตรึงต้นทาง ประเภท และยอดที่ต้องจ่าย แต่ให้ผู้มีสิทธิ์เพิ่มหรือแก้หลายสลิปและบันทึกยอดจ่ายบางส่วนได้โดยไม่แบ่งส่วนต่างให้สาขาจ่าย ห้ามลบรายการโอนโดยตรงจากโมดูลโอนเงิน

เมื่อ REX ต้นทางถูกลบหรือย้อนกลับเป็นฉบับร่าง ให้ลบรายการโอนที่เกิดจาก REX และสลิปทั้งหมดอย่างถาวรในคำสั่งเดียวกัน แม้มีสลิปจ่ายจริงแล้ว เพื่อให้วงจรของรายการโอนที่ระบบสร้างผูกกับต้นทาง การตัดสินใจนี้เลือกการลบถาวรแทนการซ่อนรายการแบบการลบรายการโอนทั่วไป และเลือกให้ลบหรือย้อน REX ได้แม้มีสลิปแทนการบล็อก ผลคือหลักฐานสลิปของรายการนั้นไม่สามารถเปิดหรือกู้คืนได้หลังคำสั่ง หาก REX หรือรายการโอนถูกล็อกโดยรายงาน ต้องลบรายงานตามกติกาเดิมก่อน จึงจะดำเนินการได้ การตรวจสอบ REX ใหม่สร้างรายการรอโอนใหม่เมื่อเข้าเงื่อนไข

รายการโอนที่จ่ายครบเข้ารายงานเป็นหลักฐานตามกติกาโอนเงินเดิม แต่ไม่เพิ่มยอดรายจ่ายสาขาเพราะ REX เลือกจ่ายภายนอก

ผู้มีสิทธิ์ตรวจสอบ REX สามารถทำให้ระบบสร้างรายการโอนอัตโนมัติได้โดยไม่ต้องมีสิทธิ์โมดูลโอนเงิน แต่การเปิดรายการโอนและจัดการสลิปยังต้องใช้สิทธิ์โอนเงินของสาขานั้น

การลบหรือย้อน REX ที่มีรายการโอนค่าทำงานต้องมีทั้งสิทธิ์ดำเนินการกับ REX และสิทธิ์โมดูลโอนเงินของสาขา เพราะคำสั่งเดียวกันลบสลิปถาวร REX ที่ไม่มีรายการโอนยังใช้สิทธิ์เดิม
