# Separate the rubber-bill evidence review workspace

Evidence review is a distinct navigation module linked visually to Rubber Bills, rather than filters and a modal embedded in the bill CRUD list. The review workspace owns period controls, review-state filters, five-card pages, evidence viewing, and review decisions; Rubber Bills keeps its evidence status, unpriced work, and a deep link to the corresponding review card. This separation keeps evidence work focused without changing period boundaries, permissions, canonical statuses, or decision rules, and supersedes only the evidence-placement and combined-badge portions of ADR-0039.

The workspace reuses the existing `useRubberBills` read model and requests evidence detail only for the current page. Preparation is staged: detail plus the first mapped image for each of at most five cards is blocking, then remaining visible evidence is fetched in the background with concurrency three. Blob identity is `(billId, revisionNo, rowId, role)`; status-only polling preserves blobs and slide position, while page, branch, revision, logout, and unmount transitions abort work and revoke URLs that leave scope. The next page is never prefetched.
