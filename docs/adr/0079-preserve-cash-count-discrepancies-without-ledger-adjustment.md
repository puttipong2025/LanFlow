# เก็บส่วนต่างการนับเงินโดยไม่ปรับรับ–จ่ายอัตโนมัติ

ข้อสรุปการออกแบบใหม่ที่ผู้ใช้ยืนยันวันที่ 2026-10-24: เปรียบเทียบเงินสดที่นับได้รวมยอดเงินในบัญชีกับรับ–จ่ายสุทธิสะสม ณ เวลานับ และเก็บยอดฐานของครั้งนั้นไว้ตรวจย้อนหลัง ยอดไม่ตรงยังบันทึกได้โดยไม่มีช่องเหตุผลในฟอร์มหรือ PDF ตามข้อแก้ไขล่าสุดของผู้ใช้ พร้อมแสดงจำนวนเงินขาดหรือเกิน โดยไม่ปรับยอดรับ–จ่ายหรือทำให้ส่วนต่างเป็นศูนย์อัตโนมัติ เพื่อรักษาหลักฐานความคลาดเคลื่อน หากพบรายการต้นทางตกหล่นให้แก้ต้นทางแล้วนับใหม่ แทนการห้ามบันทึกจนตรงจนหลักฐานยอดขาดหายไป

นำไปใช้ในโค้ดใหม่และตรวจบน local แล้ว โดยแทนแนวทางตั้งฐานอัตโนมัติของ ADR 0050 สำหรับระบบใหม่ ดู ADR 0080 และ docs/cash-count-redesign-verification.md สถานะนี้ไม่ใช่หลักฐานว่า deploy Cloud แล้ว
