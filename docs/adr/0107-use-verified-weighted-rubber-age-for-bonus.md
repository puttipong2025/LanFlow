# ใช้อายุยาง ณ ตรวจสอบแบบถ่วงน้ำหนักในการประเมินโบนัส

ข้อตกลงยืนยัน 2026-11-12 ผู้ใช้สั่งพัฒนาครบ Phase 1–4 และอัปเดต vault; พัฒนาเป็นสูตร `branch-bonus-v3` ผ่าน forward migration `20261112010000_branch_bonus_verified_age.sql` ขอบเขต Local เท่านั้น ดูหลักฐานใน `docs/branch-bonus-verification.md`

เกณฑ์อายุยางใช้ค่าอายุเฉลี่ยที่ตรึงไว้ ณ ตรวจสอบของแต่ละ REX แล้วถ่วงด้วยน้ำหนักต้นทางก่อนลดของเที่ยวในรอบโบนัส แทนการใช้อายุที่เดินต่อถึงขาย รับเข้าปลายทาง หรือวันเปิดประเมิน เพื่อให้ค่าจริงไม่เพิ่มเพียงเพราะเปิดประเมินช้าลง การถ่วงน้ำหนักทำให้ยางแต่ละกิโลกรัมมีส่วนในการประเมินเท่ากัน แต่ละเที่ยวจึงมีส่วนตามปริมาณยางแทนการนับทุก REX เท่ากัน โดยไม่รวมเวลารอหลังตรวจสอบในคะแนนอายุ

ผู้ใช้กำหนดทิศทางคะแนนให้อายุยิ่งมากกว่าเป้ายิ่งดี และใช้ตารางเพิ่ม–ลดเดิมก่อนถ่วงสัดส่วนด้านอายุยาง ผลลัพธ์จึงประเมินอายุยาง ณ ตรวจสอบตามเป้าธุรกิจนี้ รายละเอียดเป้าหมาย สัดส่วน ข้อมูลประมาณ และข้อมูลขาดอยู่ใน [การออกแบบโบนัสสาขา](../branch-bonus-design.md)
