Deleted-row age retention is superseded by ADR-0034; this age contract continues to apply while the Rubber Export source exists.

# Server-authoritative weighted rubber-export age

LanFlow จะคำนวณอายุยางของรายการส่งออกที่ Server/ฐานข้อมูลจากเวลา UTC และแสดงทุกวันเวลาเป็น `Asia/Bangkok` โดยฉบับร่างใช้เวลาปัจจุบันจาก Server เป็นเวลาตัด และรายการที่ตรวจสอบแล้วรวมถึงรายการที่ลบภายหลังตรึงเวลาตัดไว้ที่ `verifiedAt`. เวลาเริ่มรายบิลใช้ `TimestampBill` เมื่อวันที่ไทยตรงกับ `billDate`; หากวันที่ไม่ตรงให้ใช้วันที่จาก `billDate` ประกอบกับเวลาไทยเดียวกับเวลาตัดและระบุผลว่าเป็นค่าประมาณ ส่วนรายการที่ลบจากฉบับร่างไม่มีอายุอย่างเป็นทางการและบิลที่มี `billDate` หลังวันตัดไม่มีสิทธิ์เข้าส่งออก.

อายุเฉลี่ยคำนวณเป็นชั่วโมงด้วย `sum(netWeight × ageHours) / sum(netWeight)` โดยคงค่าดิบตลอดการถ่วงน้ำหนักและปัดเฉพาะผลสุดท้ายเป็นสองตำแหน่ง; อายุเก่าสุดคือค่าสูงสุดของอายุรายบิล. รายการใดมีบิลประมาณอย่างน้อยหนึ่งใบ ค่าเฉลี่ยและค่าเก่าสุดต้องระบุว่าเป็นค่าประมาณด้วย และแสดงเป็นวัน–ชั่วโมงพร้อมวันทศนิยมในตาราง รายละเอียด และ PDF.

กติกานี้เลือก snapshot และการคำนวณฝั่ง Server เพื่อให้ทุกเครื่องได้ผลเดียวกัน รักษาเวลารับซื้อของบิลที่สร้างขณะออฟไลน์ และหยุดอายุย้อนหลังไม่ให้เปลี่ยนหลังตรวจสอบ. อายุยางเป็นข้อมูลวิเคราะห์เท่านั้นและไม่เปลี่ยนต้นทุนซื้อเฉลี่ย เปอร์เซ็นต์น้ำหนักหาย ค่าทำงาน หรือรายจ่ายเดิม.

## Consequences

- รายการส่งออกต้อง snapshot เวลาเริ่มและสถานะประมาณของแต่ละบิล และตรึงเวลาตัดกับผลรวมอย่าง atomic ตอนตรวจสอบ.
- ข้อมูลย้อนหลังที่ไม่มี `TimestampBill` ใช้เวลาสร้างจาก Server เป็นค่าประมาณ และต้อง snapshot หลัง backfill.
- ฉบับร่างต้องโหลดผลจาก Server ใหม่เมื่อเข้าโมดูล เปิดรายละเอียด กลับมาโฟกัส กลับออนไลน์ และทุก 15 นาทีขณะหน้าจอเปิด.
