# แบ่งต้นทุนให้ยางคงเหลือในลานตามสัดส่วนน้ำหนัก

เมื่อจัดกองยางภายในสาขา ผู้ใช้ต้องกรอกน้ำหนักยางคงเหลือในลานโดยตรงเป็นค่ามากกว่าศูนย์และไม่เกินน้ำหนักปัจจุบันของ REX ต้นทาง บิลยางคงเหลือภายในสาขาจะรับมูลค่า `round((มูลค่ายางรวม + ยอดค่าทำงาน) × น้ำหนักยางคงเหลือในลาน ÷ น้ำหนักปัจจุบันของ REX, 2)` และไม่ย้อนแก้ REX ต้นทาง เพื่อไม่ให้ยางส่วนที่เหลือรับต้นทุนของยางทั้งกองซึ่งถูกตัดขึ้นรถไปแล้ว การรับยางจากต่างสาขายังคงรับน้ำหนักปัจจุบันและต้นทุนเต็มจำนวนของ REX โดยไม่มีช่องกรอกน้ำหนักคงเหลือ

ขอบเขตของการตัดสินใจนี้มีเพียงการสร้างบิลยางคงเหลือเพื่อใช้เป็นต้นทางของรอบใหม่ ไม่คำนวณน้ำหนักที่ขึ้นรถ ไม่เปลี่ยนสถานะขาย และไม่สร้างหรือแก้ calculation, eligibility หรือ reservation ของ WEX

## Considered Options

- ยกต้นทุนทั้งกองมาไว้ในบิลคงเหลือ: ปฏิเสธ เพราะทำให้ต้นทุนต่อกิโลกรัมของรอบถัดไปสูงเกินจริง
- แบ่งต้นทุนตามสัดส่วนน้ำหนัก: เลือก เพราะคงต้นทุนเฉลี่ยต่อกิโลกรัมของกองเดิมไว้กับยางส่วนที่เหลือ

## Consequences

- ช่องน้ำหนักเฉพาะรายการสาขาปัจจุบันเริ่มที่ `0` ใช้พฤติกรรม focus-zero แบบบิลยาง และแสดงสรุปน้ำหนักต้นทาง น้ำหนักคงเหลือ และมูลค่าคงเหลือก่อนยืนยัน
- บิลที่สร้างแล้วอ่านอย่างเดียว หากกรอกผิดต้องลบตามกติกาเดิมแล้วสร้างใหม่
- หน้ารายละเอียดบิลภายในสาขาเรียกค่านี้ว่า `น้ำหนักยางคงเหลือในลาน`; การรับจากต่างสาขาไม่เปลี่ยน
- สถานะขายและ WEX คงพฤติกรรมเดิมทั้งหมดและอยู่นอกขอบเขตการเปลี่ยนแปลงนี้
