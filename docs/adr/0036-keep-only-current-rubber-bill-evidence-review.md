# Keep only the current rubber-bill evidence review

Rubber-bill evidence review stores only the latest `ผ่าน` or `ควรปรับปรุง` decision, reviewer, and decision time for the current bill revision. Changing the decision overwrites the current values, and changing the bill revision permanently removes that review instead of retaining review history, because the product prioritizes a simple current-state workflow over historical review audit; archived Drive files remain outside this deletion rule.
