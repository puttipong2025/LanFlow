# แยกบิลรถส่งออกจากรายการขายยางออก

LanFlow ใช้บิลรถส่งออก (`WEX`) เป็นเอกสารหลักฐานการชั่งรถบรรทุกหนึ่งรายการและรถพ่วงเสริมได้อีกหนึ่งรายการ รวมถึงการจัดรายการขายยางออกขึ้นรถ โดยลำดับ 1 หมายถึงรถบรรทุกและลำดับ 2 หมายถึงรถพ่วงทั้งในบิลเดิมและบิลใหม่. ไม่ขยาย `rubber_exports` ให้เก็บการชั่งรถหรือสร้างผลเงินใหม่ เพราะหนึ่งรายการขายอาจถูกบรรทุกพร้อมรายการขายอื่นและบิลรถอาจไม่มีรายการขายเลย. WEX บันทึกสถานะชั่งเข้าได้ก่อนด้วย `outboundWeight = 0` และ `outboundAt = null`; ผู้ใช้กลับมาแก้เวลา/น้ำหนักออกภายหลังได้ และห้ามสร้าง reservation จนกว่ารถทุกคันจะชั่งออกครบ. ความสัมพันธ์ WEX → รายการขายเป็นการจองที่ฐานข้อมูลบังคับแบบ atomic: ผลรวม `currentWeight` ห้ามเกินน้ำหนักสุทธิบิลรถ, รายการที่จองห้ามยกเลิกขายหรืออยู่ใน WEX อื่น, และการแก้/ลบ WEX ปลดเฉพาะการจองโดยคงสถานะขายเดิม.
