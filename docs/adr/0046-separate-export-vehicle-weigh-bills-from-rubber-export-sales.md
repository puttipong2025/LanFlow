# แยกบิลรถส่งออกจากรายการขายยางออก

LanFlow ใช้บิลรถส่งออก (`WEX`) เป็นเอกสารหลักฐานการชั่งรถ 1–2 คันและการจัดรายการขายยางออกขึ้นรถ ไม่ขยาย `rubber_exports` ให้เก็บการชั่งรถหรือสร้างผลเงินใหม่ เพราะหนึ่งรายการขายอาจถูกบรรทุกพร้อมรายการขายอื่นและบิลรถอาจไม่มีรายการขายเลย. ความสัมพันธ์ WEX → รายการขายเป็นการจองที่ฐานข้อมูลบังคับแบบ atomic: ผลรวม `currentWeight` ห้ามเกินน้ำหนักสุทธิบิลรถ, รายการที่จองห้ามยกเลิกขายหรืออยู่ใน WEX อื่น, และการแก้/ลบ WEX ปลดเฉพาะการจองโดยคงสถานะขายเดิม.
