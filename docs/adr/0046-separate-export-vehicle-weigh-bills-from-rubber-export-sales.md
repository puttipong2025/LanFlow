# แยกบิลรถส่งออกจากรายการขายยางออก

LanFlow ใช้บิลรถส่งออก (`WEX`) เป็นเอกสารหลักฐานการชั่งรถบรรทุกหนึ่งรายการและหางพ่วงเสริมได้อีกหนึ่งรายการ รวมถึงการจัดรายการขายยางออกขึ้นรถ โดยลำดับ 1 หมายถึงรถบรรทุกและลำดับ 2 หมายถึงหางพ่วงทั้งในบิลเดิมและบิลใหม่. ผู้ขนส่งเป็นข้อมูลระดับเที่ยวที่รถบรรทุกเป็นเจ้าของ; หางพ่วงแสดงค่าเดียวกันแบบแก้แยกไม่ได้ และฐานข้อมูล canonicalize ทุกบรรทัดให้ใช้ snapshot ผู้ขนส่งของรถบรรทุก. ไม่ขยาย `rubber_exports` ให้เก็บการชั่งรถหรือสร้างผลเงินใหม่ เพราะหนึ่งรายการขายอาจถูกบรรทุกพร้อมรายการขายอื่นและบิลรถอาจไม่มีรายการขายเลย. WEX บันทึกสถานะชั่งเข้าได้ก่อนด้วย `outboundWeight = 0` และ `outboundAt = null`; ผู้ใช้กลับมาแก้เวลา/น้ำหนักออกภายหลังได้ และห้ามสร้าง reservation จนกว่ารถทุกคันจะชั่งออกครบ. ความสัมพันธ์ WEX → รายการขายเป็นการจองที่ฐานข้อมูลบังคับแบบ atomic: ผลรวม `currentWeight` ห้ามเกินน้ำหนักสุทธิบิลรถ, รายการที่จองห้ามยกเลิกขายหรืออยู่ใน WEX อื่น, และการแก้/ลบ WEX ปลดเฉพาะการจองโดยคงสถานะขายเดิม.
