# ประเมินโบนัสแยกรายการและรอบตามสาขา

รายการโบนัสหนึ่งรายการใช้ประเมินยอดโบนัสก้อนรวมสำหรับสาขาเดียว โดยเจ้าของตัดสินใจแบ่งให้พนักงานเอง และพิจารณาทั้งปริมาณรับซื้อยางกับการควบคุมต้นทุนและความสูญเสีย แต่ละสาขาเริ่มดำเนินงานและปิดรอบไม่พร้อมกัน จึงใช้ช่วงระหว่างรายการโบนัสก่อนหน้ากับรายการปัจจุบันของสาขานั้นเป็นรอบประเมิน โดยเจ้าของเลือกวันเริ่มต้นสำหรับรายการแรกของแต่ละสาขาเอง การรวมทุกสาขาในรอบเดียวจะไม่ตรงกับจังหวะดำเนินงานจริง และการเปลี่ยนขอบเขตรอบภายหลังมีผลต่อความหมายของประวัติประเมินที่สะสมไว้

บันทึกนี้เป็นข้อตกลงออกแบบ ยังไม่ได้กำหนดสูตร จำนวนเงิน หรือรายละเอียดการนับวันบริเวณรอยต่อรอบ และยังไม่ได้พัฒนาฟังก์ชันโบนัส
