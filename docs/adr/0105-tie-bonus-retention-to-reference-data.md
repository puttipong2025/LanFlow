# ให้รายการโบนัสมีอายุตามข้อมูลอ้างอิง

ผู้ใช้มีแผนล้างข้อมูลธุรกิจในอนาคตเพื่อลดปริมาณข้อมูล และยืนยันว่าเมื่อล้างข้อมูลอ้างอิง รายการโบนัสที่เกี่ยวข้องให้หายไปด้วย จึงไม่สร้างคลังข้อมูลหรือเก็บผลโบนัสแยกไว้เพื่อเปิดดูหรือคำนวณใหม่หลังล้างข้อมูลอ้างอิง โดยยอมให้ประวัติโบนัสดังกล่าวสิ้นสุดตามข้อมูลที่รองรับการประเมิน

ยังต้องตกลงว่าการล้างข้อมูลอ้างอิงเพียงบางรายการมีผลต่อรายการโบนัสทั้งรายการอย่างไร การตัดสินใจนี้ยังไม่รวมการแก้ไขบิลตามปกติ และยังไม่ได้ดำเนินการล้างข้อมูลหรือพัฒนาฟังก์ชันโบนัส
