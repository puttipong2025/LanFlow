# Require threshold configuration before a new branch joins Dashboard alerts

LanFlow keeps the existing global Telegram enable switch and does not add a per-branch toggle. A newly added branch remains active for normal work and Dashboard calculation, but its Dashboard values are excluded from Telegram until a system manager saves that branch's thresholds for the first time in the existing Telegram settings modal. Existing branches retain their current configured thresholds during migration. This prevents an empty branch from repeatedly reporting zero-value alerts while preserving one global delivery switch; the trade-off is that an active branch can remain outside Dashboard alert evaluation until its initial threshold save is completed and the UI must make that unconfigured state visible.
