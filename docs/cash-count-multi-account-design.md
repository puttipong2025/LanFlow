# ขยายการนับเงินเป็นหลายบัญชี

สถานะ: ผู้ใช้ยืนยันเริ่มงานแล้ว ดำเนินการขยายจากหนึ่งเป็น 0–4 บัญชีบน local; ผลตรวจดู cash-count-multi-account-verification.md ไม่ใช่หลักฐาน Cloud deploy

## ข้อตกลงที่ยืนยันแล้ว

- ยอมให้บัญชีซ้ำกันได้ ใช้ผู้ตรวจดูรูปแทนการตรวจซ้ำอัตโนมัติ ตามข้อแก้ไขล่าสุดของผู้ใช้
- ตัดข้อกำหนดเดิมเรื่องอ่านธนาคาร/เลขท้ายบัญชีและบล็อกบัญชีซ้ำออก OCR อ่านเฉพาะยอดเหมือนระบบเดิม
- หากช่องใดอ่านยอดไม่ชัด จะบันทึกทั้งรายการไม่ได้จนกว่าจะถ่ายช่องนั้นใหม่หรือนำช่องนั้นออก ห้ามข้ามช่องนั้นแล้วรวมยอดเงียบ ๆ
- บันทึกใบนับเงินได้เมื่อรูปทุกช่องที่เลือกใช้เก็บลง Drive สำเร็จ หากบางช่องล้มเหลวให้คงข้อมูลและรูปไว้ แล้วลองใหม่เฉพาะช่องที่ยังไม่สำเร็จ ไม่ต้องถ่ายใหม่หรืออัปโหลดรูปที่สำเร็จแล้วซ้ำ ทั้งนี้ยังอยู่ภายในรอบนับเดิมที่ไม่หมดเวลา
- รายละเอียดและ PDF ใช้ชื่อ “บัญชี 1–4” พร้อมยอดแต่ละช่องและยอดบัญชีรวม ไม่เพิ่มช่องกรอกชื่อบัญชีหรือธนาคาร รูปหลักฐานเปิดดูแยกแต่ละช่องในรายละเอียด และไม่ใส่รูปใน PDF

## ขอบเขตที่ยืนยันให้นำไปพัฒนา

- 0–4 บัญชีต่อรายการ เพิ่มช่องแล้วถ่ายทีละบัญชี ช่องละหนึ่งรูปพร้อมยอด readonly และการยืนยันตรงกับรูป
- ถ่ายใหม่หรือนำออกแยกช่อง รวมยอดบัญชีทุกช่องกับเงินสดเพื่อเทียบฐาน ณ เริ่มนับ
- PDF แสดงยอดรายบัญชีลำดับ 1–4 และยอดบัญชีรวม

รูปแบบแสดงล่าสุดที่ผู้ใช้ยืนยัน: `บัญชี1 = 10,000.00 บาท` ไล่ตามจำนวนจริงถึงบัญชี4 ทั้งฟอร์ม รายละเอียด และ PDF ไม่ใช้ตัว N เป็นข้อความบนหน้าจอ
